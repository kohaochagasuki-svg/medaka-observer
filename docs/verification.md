# 動作確認記録

確認日：2026-11-03。Node.js 24 / jsdom 26を使用。

## 確認済み

`npm run check`：JavaScript構文検証と次の6件のDOMテストを実施。

| 確認対象 | 結果 |
| --- | --- |
| 動画選択、再生・停止、シーク、速度変更、差し替え時のblob URL解放 | 合格 |
| 縦長映像の余白除外、ポインター移動、向き・表示切替、リセット、キー操作 | 合格 |
| 条件・メモ・中央線設定の保存／復元、動画自体を保存しないこと | 合格 |
| 自動保存、空／非動画ファイル、動画読み込みエラー、保存失敗／記録破損の表示 | 合格 |
| 再生時間不明時のシーク制限、ページ非表示時の停止 | 合格 |
| CSPによる外部送信制限、外部URL依存のない本番ファイル、未実装の表示 | 合格 |

動画の時間・デコード・Pointer Captureはテスト環境で模擬している。「30分」のテストは1800秒のメタデータを模擬したもので、実際の30分ファイルをデコードした結果ではない。

## 未確認と確認手順

この環境にはSitesで指定されたブラウザ操作ツール `cua_repl.js` がなく、ブラウザQAは実施できなかった。Pixel 8aの実機も接続されていない。

- Pixel 8a / Chromeでの本物の動画選択、デコード、音声再生
- 30分動画の連続再生、シーク、ピークメモリ、発熱
- 画面幅320px・360px・412pxと横画面での実描画、はみ出し、指の操作感
- 対応外コーデック、破損ファイル、連続した動画差し替え時の実機挙動
- 端末保存の復元、ブラウザを閉じて再度開いた場合の挙動

READMEの「Pixel 8aでの確認」に沿って確認する。観察にはまず1080pまたは720pのMP4（H.264）を推奨する。実際の撮影条件で30分動画を試し、必要なら解像度とビットレートを下げて比較する。低メモリ動作や自動計数の精度を検証済みとは扱わない。
